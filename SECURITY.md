# Security Policy

## Reporting a Vulnerability

You can report security issues in two ways:

- **Publicly** — open a regular issue: https://github.com/f-link4/pppoe_toggle_ha/issues
- **Privately** — use a security advisory (for sensitive issues only): https://github.com/f-link4/pppoe_toggle_ha/security/advisories/new

If the issue could be exploited by someone else before a fix is available, please use the private channel first.
